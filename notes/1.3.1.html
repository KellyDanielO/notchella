Slimmer activities

  • Wings that fit what they show. Agent timers, Xcode builds, downloads and charging take up less room beside the notch. Only longer states, like a finished build or several agents at once, get wider.
  • Long timers no longer cut off. An agent session or build that runs past an hour shrinks its timer slightly to fit.

Anonymous usage counts

  • Notchella now sends anonymous counts of launches, a daily "in use" ping and which tabs get opened, so I can tell what's worth improving. No personal data and no device identifier.
  • Turn it off any time in Settings → Privacy.

Notchella is free and open source.
